Fit to image rounds the size so a whole number of cells spans the image, so the result still tiles (at 0°, 90°, 180° and 270°).

Color

Follows the edge of the visible shape (alpha at or above the threshold). On an opaque texture, Inside draws a frame. If an outside outline gets cut off, add room with Canvas size.

Tiled view

Borders hide thin seams, so check with them off too. The view only; export is always one tile.

Offset cross-fade blends in a copy shifted by half the image, which wraps cleanly; it suits organic textures (stone, grass, noise). Mirror blend averages each edge with the opposite one. Width is how far in from the edges the blend reaches.

Removes uneven light (a bright corner, a dark side) that makes repeats stand out. Runs first, before Color. Radius is a share of the image size: smaller flattens more.

Shifts the image with wrap-around, so the edges meet in the middle where seams are easy to see. Runs last; turn it off before exporting unless you want the shift.
