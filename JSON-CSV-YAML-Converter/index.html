Writing CSV

      
Nested objects become dot columns such as ship_to.city, and lists are written as JSON text in one cell.

    

    

      
Reading CSV

      
The delimiter is detected for you. Turn on Nest dotted columns to rebuild nested objects from dot columns.

    

    

      
YAML and JSON Lines

      
A YAML file with several documents separated by ---, or a JSON Lines file, becomes one list.
