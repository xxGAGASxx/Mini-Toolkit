Sprite Cutter

Find the sprites in a sheet and cut them out.

Detection

Background
#FFFFFF
Current

Transparent pixels are the background.

0

Pixels at or below this opacity count as background. Raise it to trim soft edges and split sprites joined by a faint glow.

px

Ignores anything smaller than this on both sides.

Extraction

Keeps only the sprite's own pixels. Everything else in its rectangle is transparent.

0 px

Fades each sprite's outer edge over this many pixels. Leave at 0 for pixel art.

Export

The sheet is an even grid sized to the largest sprite. Grid and cell size are in the file name.
